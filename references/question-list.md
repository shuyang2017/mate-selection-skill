# 择偶判断问题清单（第一性原理版）

本清单对应 `SKILL.md` 的拆解框架，按"先问自己 → 再评估对方 → 最后现实检验"三层组织。建议每题用 1–5 打分（5 最好），并明确标注哪些是"一票否决 / Dealbreaker"。

用法顺序：先过第 7 步 Dealbreaker，5 分钟问清、省几个月；其余逐维打分。第 2、4 维权重最高，第 3 维保底即可。

---

## 0. 目标函数自检（最先答，决定后面所有权重）

1. 我到底想从关系里得到什么？试着只列 3 个词（陪伴 / 成长 / 稳定 / 激情 / 养育 / 社会认可…）。
2. 我是在"选长期合伙人"，还是在"完成结婚 KPI"或"缓解孤独焦虑"？
3. 如果对方条件满分但完全聊不来，我愿意过几十年吗？（这题能戳破你真正优化的目标）
4. 我能为关系投入多少时间、情绪和妥协？我的底线画在哪？

## 1. 价值 / 目标契合

1. 对"要不要孩子、要几个、怎么带"是否一致？
2. 对钱的态度（储蓄 / 消费 / 风险承受）是否兼容？
3. 人生优先级是否同频（事业冲刺 vs 安稳生活 vs 家庭中心）？
4. 底层价值观（诚实、公平、责任）是否一致？
5. 生活方式（饮食、烟酒、作息、信仰）能否长期共存？

## 2. 关系机制（冲突修复能力，最预测长期成败）

1. 吵架后，TA 是冷暴力、攻击，还是能回来沟通？
2. TA 能否承认错误、道歉，并真正调整行为？
3. 压力下 TA 是向内塌缩还是向外攻击？
4. 分歧能否"暂时搁置也彼此安心"？
5. 情绪是否稳定？有无反复出现的控制 / 贬低行为？

## 3. 相互吸引力（保底即可，不必追极致）

1. 物理吸引是否持久成立（不止初见）？
2. 智力 / 思维上是否互相欣赏、聊得来？
3. 相处是"充电"还是"耗电"？
4. 性方面的意愿与节奏是否匹配？

## 4. 品格 / 可靠（长期防崩盘的关键）

1. TA 对不在场的人（服务员、前任、家人）是否尊重？
2. 承诺过的小事是否兑现？（看信用密度，不只看大事）
3. 财务是否透明？有无隐藏债务 / 成瘾？
4. 遇困难时 TA 是甩锅还是担责？
5. 朋友圈 / 过往关系是否显示稳定履约的记录？

## 5. 互补性

1. TA 的长板是否补上我的短板（情绪 / 务实 / 社交 / 规划）？
2. 是否"一个人搞不定的事，两个人能搞定"？
3. 角色分工是否自然且不积怨？

## 6. 结构性约束（现实检验，常被忽略）

1. **接触面**：我现在的圈子 / 渠道，能不能遇见这类人？（池子够不够）
2. **双边**：以我当前状态，我配得上我想找的人吗？（诚实估价自身 offer）
3. **时间**：我了解 TA 真实人品多久了？是否还在"最佳表现期"的伪装窗口？
4. **权衡**：TA 不可能全项满分，我能否接受"核心项够好、其余普通"？

## 7. 硬性分歧前置排查（Dealbreaker，5 分钟问清，省几个月）

- 生育意愿与数量
- 定居城市 / 异地容忍度
- 对忠诚 / 开放式关系的定义
- 成瘾行为（烟酒赌、消费贷）
- 重大债务 / 财务隐瞒
- 与原生家庭的边界（是否"妈宝" / 过度啃老）

**任一项硬冲突 → 不必继续投入。**

---

## 用法建议（权重与排序）

- **顺序**：先过第 7 步 Dealbreaker，不过直接止损；再打分第 1–5 维。
- **权重**：第 2、4 维（关系机制、品格）权重最高；第 3 维（吸引）保底即可。
- **代理指标**：收入、身高、房车、学历只作**门槛过滤**，不当"打分排序"依据——它们和核心维度相关度有限。
- **承诺判断**：核心维度"足够好"就进入第 6.4 的承诺判断，**别无限搜寻**（时间成本和"隔壁更绿"错觉会吃掉价值）。
