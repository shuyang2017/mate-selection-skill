# first-principles-mate-selection

> 用第一性原理、去惯例化地分析婚恋择偶的结构化方法论 + 一份可操作的判断问题清单。

把"找对象"还原为"选长期人生合伙人"：先重写目标函数，再拆到不可再分的 5 个核心维度，正视 4 个结构性约束，最后推出行动。帮你区分**真正预测长期成败的核心维度**与容易误导的**代理指标**（收入 / 房车 / 身高 / 学历）。

## 核心框架（四步）

1. **重写目标函数** —— 择偶 = 选长期人生合伙人；最大化终身合伙价值，最小化崩盘风险（而非"看着厉害"）。
2. **拆到 5 个核心维度** —— 价值/目标契合、关系机制、相互吸引力、品格/可靠、互补性。
3. **正视 4 个结构性约束** —— 接触面、双边、时间/信息不对称、维度权衡。
4. **推出行动** —— 扩大候选池、投资自身、聚焦核心维度、前置排查分歧、适时承诺。

## 作为 WorkBuddy Skill 使用

将整个文件夹复制到：

- 用户级（跨项目）：`~/.workbuddy/skills/first-principles-mate-selection/`
- 项目级（团队共享）：`<repo>/.workbuddy/skills/first-principles-mate-selection/`

重启 / 刷新 WorkBuddy 后，对话中提到"用第一性原理分析择偶""给我一份择偶判断清单"等即会触发。

## 作为纯文档使用

`references/question-list.md` 是一份独立可用的清单，可直接复制、打印或转成自己的评分表。两张 SVG 图可嵌入博客、笔记或社交平台。
